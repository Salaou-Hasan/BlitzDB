# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within BlitzDB, please send an email to the maintainers. All security vulnerabilities will be promptly addressed.

Please do not report security vulnerabilities through public GitHub issues.

## Security Measures

BlitzDB is designed with security as a first-class concern:

- Authentication is built into the platform
- Authorization policies are enforced close to data access
- Input validation is performed at the protocol level
- Resource limits prevent exhaustion attacks
- Application code execution is sandboxed where possible

## Security Updates

Security updates will be released as patch versions. Users should always run the latest patch version of any release.

## Contact

For security-related inquiries, please contact the maintainers directly.
